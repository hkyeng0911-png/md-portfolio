데이터 준비 방법
  1. Colab 코드로 수집(권장) — colab_복종별_판매추이예측.py에 네이버 API 키를 넣어 실행하고, 내려받은 복종별_판매추이예측.xlsx를 그대로 올리세요. '지수실적' 시트를 읽어 이 화면에서 다시 예측합니다.
  2. 데이터랩 웹에서 직접 — datalab.naver.com 검색어트렌드·쇼핑인사이트에서 기간 단위를 '주간'으로 조회하고 엑셀로 내려받아 올리세요. 날짜 열과 키워드 열이 있는 표는 자동으로 인식합니다.
  3. 직접 만든 표 — 첫 열 주차(날짜), 다음 열부터 복종별 지수인 CSV·엑셀.
  4. 판매수량(선택) — 열 이름 주차, 복종, 판매수량. 복종 이름이 지수 데이터와 같아야 연결됩니다. 연결되면 지수로 판매량을 추정한 R²와 예측 판매수량이 나옵니다.
  5. 네이버 API는 키가 드러나지 않도록 서버(Colab)에서 호출해야 해서, 이 화면은 수집된 결과를 올려 보는 방식입니다. 올린 파일은 이 브라우저 안에서만 처리되고 어디로도 전송·저장되지 않습니다.

다품번 일괄 판단

엑셀에서 아래 열 순서대로 복사해 붙여넣으세요(첫 줄 머리글). 수수료·탄력성·회수율·불확실성·주간 변화율은 왼쪽 값을 공통으로 씁니다. 처음 내용은 예시입니다.

품번판매율재고 소진(주)추천 할인율추천 리오더예상 판매시즌말 판매율남은 시즌 기대이익현 상태 유지 대비판정

계산 방식 — 주차별 수요 = 최근 주평균 판매 × (1+주간 변화율)^주차 × (1−할인율)^−탄력성. 리오더는 리드타임 이후 수요에만 쓰입니다. 예상 판매는 수요를 정규분포(평균, 평균×불확실성)로 보고 재고 한도 내 기대판매량을 계산합니다. 기대이익 = 예상 판매 × 장당 순매출 + 시즌말 재고 × 원가 × 회수율 − 리오더 수량 × 리오더 원가 − 리오더 고정비. 이미 입고된 재고의 원가는 어떤 선택을 해도 같으므로 비교에서 뺐고, '시즌 전체 손익'에만 넣었습니다. 장당 순매출 = 판매가 ÷ 1.1 × (1 − 수수료율 − 기타 변동비율).
